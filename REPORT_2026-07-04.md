# Отчёт по работе — 04.07.2026

## Задача

Создать анимацию взлёта UFO на экране CYD (ESP32-2432S028, ILI9341 320x240) с использованием ESPHome + LVGL.

---

## Методика создания анимации

### Архитектура анимации

```
Коллаж (JPEG/PNG) → Нарезка на кадры → Обработка → RGB565 (C-массив) → LVGL animimg
```

**Компоненты цепочки:**
1. **Источник** — коллаж 8 кадров анимации (сетка NxM)
2. **Нарезка** — Python + Pillow, вырезает каждый кадр по координатам
3. **Масштабирование** — каждый кадр масштабируется до 320x240, центрируется на чёрном холсте
4. **Обработка** — удаление текста, артефактов, добавление полей
5. **Компиляция** — ESPHome конвертирует PNG → RGB565 (2 байта/пиксель) → C-массив
6. **Рендеринг** — LVGL `animimg` проигрывает кадры с заданной скоростью

### Как работает animimg в LVGL

```yaml
- animimg:
    id: lv_ufo_anim
    x: 0
    y: 0
    width: 320
    height: 240
    src:
      - ufo_f0    # Каждый кадр — это RGB565 C-массив
      - ufo_f1
      - ufo_f2
      - ufo_f3
    duration: 800ms   # Полный цикл анимации
```

- `src` — список image-идов, каждый загружается как RGB565 C-массив
- `duration` — время одного цикла (все кадры показываются за это время)
- Кадры автоматически зацикливаются

### Формат изображений

| Параметр | Значение |
|----------|----------|
| Разрешение кадра | 320x240 |
| Формат | RGB565 (16-bit) |
| Размер 1 кадра в RAM | 320 × 240 × 2 = **153,600 байт** |
| Размер C-массива | ~1.5MB текста (каждый байт = "0xHH, ") |
| Flash для 4 кадров | ~600KB данных + фреймворк |
| Flash для 8 кадров | ~1.2MB данных + фреймворк |

### Методика нарезки коллажа

**Шаг 1: Анализ структуры** (`analyze_collage.py`)
- Ищет горизонтальные и вертикальные белые линии (разделители)
- Определяет количество строк/столбцов и координаты ячеек

**Шаг 2: Нарезка** (`slice_new_ufo.py`)
```python
# Координаты ячеек определены анализом
frames = [
    (0, 0, 441, 292),       # Левый верхний
    (0, 304, 441, 594),     # Левый второй
    # ...skip white lines...
    (454, 910, 895, 1199),  # Правый нижний
]

# Каждый кадр:
# 1. Вырезается из коллажа
# 2. Масштабируется в 320x240 (min scale для сохранения пропорций)
# 3. Центрируется на чёрном холсте 320x240
```

**Шаг 3: Очистка** (`remove_text.py`, `fix_margins.py`)
- Удаление текстовых подписей (чёрные прямоугольники в углах)
- Закраска артефактов (20px чёрные поля по краям)

**Шаг 4: Интеграция**
- Копирование кадров в `esphome/ufo_anim/`
- Добавление `image:` блоков в YAML
- Добавление `animimg:` виджета в LVGL страницу

## Решённые проблемы

### Проблема 1: Compilator OOM (нехватка RAM компилятора)

**Симптом:** `cc1plus.exe: out of memory allocating 16781311 bytes`

**Причина:** ESP-IDF компилятор (cc1plus.exe) — 32-битный процесс. Генерация C-массивов для 8 кадров 320x240 RGB565 = ~10MB исходного кода. Компилятору не хватает адресного пространства.

**Факторы:**
- Windows Defender (MsMpEng) съедает **2.3GB RAM**
- Всего 7.8GB RAM, свободно ~2.7-3.7GB
- ESP-IDF + LVGL + все компоненты ESPHome — тяжёлые

**Решения:**
1. Закрытие Chrome/Edge/OneDrive перед сборкой → +1GB RAM
2. Ограничение числа кадров до 4 (600KB вместо 1.2MB)
3. Очистка кэша сборки перед каждой попыткой

**Эффективно:** 4 кадра 320x240 RGB565 компилируется за ~5 минут.

### Проблема 2: Flash-лимит (прошивка не влезает)

**Симптом:** `Error: The program size (2391875 bytes) is greater than maximum allowed (1835008 bytes)`

**Причина:** ESP32 4MB flash, раздел приложения по умолчанию — **1.79MB**. Прошивка с 8 кадрами = **2.39MB**.

**Решение:** Использование 4 кадров вместо 8 → прошивка **1.78MB** (впритык).

**Попытки увеличить:**
- `huge_app.csv` (3MB раздел) — ESPHome не принимает кастомный формат
- `partitions: huge_app.csv` — файл не найден в ESPHome
- Правильный формат CSV создан, но ESPHome падает с ошибкой парсинга

**Итог:** 4 кадра — максимум для ESP32 4MB с ESPHome + LVGL.

### Проблема 3: JPEG-артефакты (полосы на экране)

**Симптом:** Тонкие горизонтальная и вертикальная полосы на экране, мигают (не на всех кадрах).

**Диагностика:**
1. Анализ пикселей показал ненулевые значения в краевых столбцах (x=0)
2. frame_04: 181 пиксель > 2 в x=0
3. frame_07: 180 пикселей > 2 в x=0
4. Причина — JPEG-сжатие размывает белые разделители коллажа, 1-2px "просачиваются"

**Решение:**
1. На **ВСЕХ** кадрах закрашено чёрным 20px слева и 20px сверху
2. LVGL animimg: `pad_all: 0`, `border_width: 0`, `outline_width: 0`, `bg_opa: 0`

**Важно:** Недостаточно закрашивать только проблемные кадры — артефактыJPEG могут появиться на любом кадре.

### Проблема 4: AnimatedGIF не работает

**Попытка:** Использовать AnimatedGIF библиотеку (bitbank2) для декодирования GIF в runtime — эффективнее по flash.

**Симптом:** `fatal error: ../../lv_conf_internal.h: No such file or directory`

**Причина:** `AnimatedGIF.h` из LVGL-кэша содержит `#include "../../lv_conf_internal.h"`. Когда файл копируется отдельно от LVGL — путь ломается.

**Решение:** Отказ от GIF, использование LVGL animimg.

### Проблема 5: Смена IP адреса

**Симптом:** ESP32 получил IP .15 вместо привычного .16.

**Причина:** DHCP назначает адрес динамически.

**Решение:** Статический IP в конфиге:
```yaml
wifi:
  manual_ip:
    static_ip: 192.168.1.16
    gateway: 192.168.1.1
    subnet: 255.255.255.0
```

### Проблема 6: ESP32 недоступен после OTA

**Симптом:** `Connection to 192.168.1.16 port 3232 failed: timed out`

**Причина:** Прошивка упала при загрузке (ошибка в коде или нехватка flash).

**Решение:** Прошивка через USB-Serial (COM5, CH340):
```bash
esphome upload cat_litter_v2.yaml --device COM5
```
Логи по serial показали успешную загрузку WiFi и получение IP.

### Проблема 7: Кривая нарезка коллажа

**Симптом:** Первые попытки нарезки давали кадры 320x857 (слишком высокие), UFO обрезался.

**Причина:** Неправильное определение структуры коллажа (считали 4x2 вместо 2x4).

**Решение:** Анализ белых разделительных линий (`analyze_collage.py`) показал:
- Вертикальная линия: x=442-453 (12px) → 2 столбца
- Горизонтальные: y=293-303, y=595-606, y=898-909 → 4 ряда
- Итого: **2x4** сетка, каждый кадр ~441x291

## Конфигурация ESPHome

### Основные параметры (`cat_litter_v2.yaml`)

| Параметр | Значение |
|----------|----------|
| Платформа | ESP32-D0WD-V3 (CYD) |
| Фреймворк | ESP-IDF 5.5.4 |
| Дисплей | ILI9341 320x240, SPI (VSPI) |
| Тачскрин | XPT2046, SPI (HSPI) |
| Радар | HLK-LD2410C (UART2, 256000 baud) |
| Серво | MG995 (GPIO27, PWM 50Hz) |
| Wi-Fi | K2, статический IP 192.168.1.16 |
| LVGL | rotation: 180, buffer: 25%, big_endian |

### Состояния конечного автомата

```
IDLE → DETECTING (5 сек) → CAT_INSIDE → COOLDOWN (30 сек) → CLEANING → IDLE
```

### Анимация

```
Touch → show_ufo_animation → LVGL page ufo → animimg plays 4 frames
→ delay 2.5s → servo activates → delay 2s → servo returns → back to cat page
```
